# Adapter — independent run

```sh
cd asset-provenance-adapter
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python smoke.py
node check-js.mjs
```

CPU Python and browser-safe JavaScript, with ten synthetic authored contour/schema/mesh cases. The core functions are inflate_source, import_asset, and to_renderer. Original private fish/owl GLBs, research logs, and host-specific browser harnesses remain private. Check real asset defects using your own licensed GLBs. Automatic repair, rig inference, and physics are not implemented.
